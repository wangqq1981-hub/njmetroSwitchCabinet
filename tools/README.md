# Decompilers

Vendored command-line decompilers used by `scripts/decompile.sh`.

| File | Project | Version |
|------|---------|---------|
| `vineflower-1.12.0.jar` | [Vineflower](https://github.com/Vineflower/vineflower) | 1.12.0 |
| `cfr-0.152.jar` | [CFR](https://github.com/leibnitz27/cfr) | 0.152 |

Vineflower is the source written to `src/main/java`. CFR output is kept under `work/decompiled-cfr` when a class is hard to read.
